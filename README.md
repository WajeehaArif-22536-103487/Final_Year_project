# 🎓 Final Year Project Portal

A MERN Stack web application designed to streamline the management of Final Year Projects in educational institutions. The portal allows students to submit project proposals, teachers to review and approve them, and provides a centralized repository for completed projects.

---

## 🚀 Features

### 👨‍🎓 For Students

- Register and login securely
- Submit Final Year Project proposals
- Upload final project files
- View proposal status
- Update profile information

### 👨‍🏫 For Teachers

- Secure login
- Review submitted proposals
- Approve or reject proposals
- View student project details
- Manage uploaded projects

  ### 👨‍🏫 For Admin

- Secure login
- Manage Users
- Register Faculty
- Assign Supervisor

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/final-year-project-portal.git
```

### Install Dependencies

```bash
cd client
npm install

cd ../server
npm install
```

### Environment Variables

Create a `.env` file.

```
PORT=5000
MONGO_URI=Your MongoDB Connection String
JWT_SECRET=Your Secret Key
```

### Run Project

Backend

```bash
npm start
```

Frontend

```bash
npm start
```
